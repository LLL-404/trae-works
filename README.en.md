## ⌨️ Quick start

Every project runs on its own — step into a directory and read its README:

```bash
cd signbridge/   # AI sign language translation
cd game/         # 3D autobattler roguelike
cd GitInsight/   # Git contribution visualization
cd Web-call/     # FaceLink video calling
```
